# La Vie des Plantes – Site e-commerce WordPress

# Présentation du projet

Site e-commerce développé sous WordPress pour l’entreprise fictive « La Vie des Plantes », spécialisée dans la vente de kits de plantation et accessoires de jardinage.

Le projet permet :
- la présentation des produits
- la vente en ligne via WooCommerce
- la gestion d’une boutique e-commerce
- la mise en place d’une identité graphique cohérente.


# Technologies utilisées

## Technologies principales :
- WordPress
- WooCommerce
- Elementor
- PHP
- HTML / CSS
  
## Thème utilisé :

Flower Shop Lite
