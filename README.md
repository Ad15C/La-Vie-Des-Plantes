La vie des plantes – Site e-commerce WordPress
# Présentation du projet

Ce projet consiste à créer un site e-commerce sous WordPress pour l’entreprise La vie des plantes, spécialisée dans la vente de kits de plantation, graines et accessoires de jardinage.

L’objectif du site est de permettre à l’entreprise de :
- présenter ses produits
- vendre des kits de plantation en ligne
- augmenter sa visibilité
- toucher une clientèle urbaine âgée de 25 à 35 ans

Le site a été réalisé dans le cadre d’un projet pédagogique portant sur l’installation et la configuration d’un CMS avec e-commerce.

# Objectifs pédagogiques

Grâce à ce projet, les compétences suivantes sont mises en pratique :
- Installer une solution CMS (WordPress)
- Installer et configurer une solution e-commerce
- Maintenir une solution CMS en prenant en compte les aspects sécurité
- Construire la structure d’un site web
- Utiliser un gabarit de mise en page (thème)
- Installer un thème externe
- Adapter un thème à une identité graphique
- Concevoir un site multilingue
